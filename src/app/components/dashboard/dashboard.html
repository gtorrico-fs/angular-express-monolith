Características del Monolito

Proceso Unificado
  • memory

    Despliegue en Único Contenedor

    El cliente (Angular SSR) y la API REST son compilados y servidos en la misma unidad de ejecucion de Cloud Run.

  • api

    Rutas REST nativas (/api/*)

    Simulador JSON-Server integrado en el servidor Express, con sincronización de estado en db.json.

  • palette

    Diseño 100% SCSS Puro

    Sin dependencias de Tailwind CSS. Variables SCSS, mixins de diseño, Flexbox y CSS Grid personalizado.
